# ADR 0004: MIT license

**Status:** Accepted (30.09.2026)

## Context
Standard for Claude skills; widest reuse.

## Decision
MIT.

## Consequences
Anyone may use or resell it and must keep the copyright notice in the code; the footer credit is not enforceable.

## Alternatives
Apache 2.0 (patent clause, more formal); attribution-required licence (non-standard, deters companies).
